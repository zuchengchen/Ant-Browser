### Scope

1. 内核归档解压安全：修复 TAR 符号链接和父路径链接导致的目录越界写入，检查相关归档写入路径；保持正常归档及合法目录内链接可用。
2. 快照恢复安全：先在独立临时目录解压和校验，再安全替换目标目录；恢复失败保留或回滚原数据，正确处理运行实例、替换错误和临时资源清理。
3. 虚拟分组轮询：校验、预热等非启动操作不消耗启动游标；真正选定启动成员后再提交选择，保持 sticky、健康筛选和故障切换行为。
4. 启动队列并发：修复 releaseCh、waiting 等相关状态的无保护访问，保证释放名额、通知和等待行为正确。
5. 分片下载：校验分片响应状态、Content-Range、长度及文件写入结果；正确报告重试耗尽、取消和异常响应，保留正常并行下载及单流回退。
6. Linux 桥接测试：按当前 Linux 架构选择适用的 Xray，修复同类测试中的 Windows 路径依赖；真实启动和必要的连通性验证必须运行，测试不得修改仓库运行时文件。
