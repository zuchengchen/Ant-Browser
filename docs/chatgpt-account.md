# ChatGPT 账户查询

在实例列表中，点击目标实例的 **获取 GPT 账户信息** 按钮。卡片视图也有同名按钮。

查询会启动所选实例，沿用它的代理连接栈、浏览器配置和登录状态，在独立标签页读取 ChatGPT 的账户、用量和账单设置。查询结果按实例自动保存到本地数据库，并显示“已获取并保存”和保存时间。

之后点击 **更多 → 查看 GPT 账户信息**（卡片视图有同名按钮），直接查看最近一次保存的结果。查看不会启动实例或联网；重启软件后仍可查看。弹窗中的 **获取 GPT 账户信息** 可以再次读取并保存最新结果。

如需登录，在已从 KeyPouch 同步凭据的实例里点地址栏旁的「登录 GPT」。扩展从 ChatGPT 首页点「Log in」，逐字输入邮箱、密码，以及网站要求的验证器动态码。每个字符间的停顿会变化。其他实例可在扩展里使用 KeyPouch 授权或选择邮箱，也可以直接在 ChatGPT 页面登录。邮箱验证码和人机验证需要在浏览器中手动完成。账户查询弹窗会等待并自动继续，最多等待 10 分钟。关闭弹窗会停止后续轮询，浏览器窗口保留。

## 结果字段

| 字段 | 含义 |
| --- | --- |
| 显示名、用户名、登录邮箱 | ChatGPT 账户页显示的身份信息；用户名可能尚未设置 |
| 订阅类型 | 当前页面显示的套餐 |
| 订阅到期 | 账单页明确标注的到期日期 |
| 下次续费 | 账单页明确标注的续费日期，与到期日期分开显示 |
| 本周额度、5 小时额度 | 用量页显示的剩余百分比及重置倒计时 |
| 积分 | 用量页显示的可用积分余额 |
| 可用重置卡 | 用量页显示的可用额度重置次数，不统计历史已使用次数 |

网页将这些额度标注为 Codex、Work 等共享额度时，结果也显示该范围。日期和倒计时保留获取当时的网页文字，并记录获取时间和保存时间；保存的信息不会实时更新。账单金额、账户货币余额和 API 平台的余额不作为这里的积分。

缺失或尚未加载的数据保留为“页面未提供”，接口使用 `null`，与明确读取到的 `0` 区分。如果实例名称包含邮箱，查询会核对登录邮箱；不匹配时停止读取订阅和用量并提示实际登录邮箱。

## 实现与验证

桌面接口 `BrowserChatGPTAccountRead(profileId)` 通过已有实例启动流程和浏览器 CDP 执行页面读取，成功后保存；`BrowserChatGPTAccountGet(profileId)` 只读取本地结果，无记录时返回 `null`。数据库迁移 35 添加 `browser_chatgpt_accounts`，以实例 ID 保存一个完整 JSON 快照。页面读取逻辑集中在 `backend/chatgpt_account_reader.js`，前端入口和结果弹窗位于实例模块。该功能不需要启用 Playwright 自动化运行时。

账户查询只涉及打开页面、切换账户设置栏目和读取可见文字，不会兑换重置卡、购买积分或修改订阅。

登录验证、账号不匹配、读取失败或未取得登录邮箱时保留之前保存的结果。有效的部分结果会完整替换旧快照，缺失项显示“页面未提供”，避免拼接不同时间的数据。数据库保存失败会明确报错，不提示保存成功。每个实例的结果独立；新建、克隆实例不会继承来源实例的查询记录。移入回收站保留记录，恢复实例后可继续查看；彻底删除实例时级联删除记录。

页面布局变化、未支持的语言、网络故障或网站验证可能导致部分字段无法读取。此时保留已取得的结果，显示具体缺失项，并提供重试。

解析与流程测试：`node --test frontend/scripts/test-chatgpt-account.mjs`。Go 测试覆盖 CDP 事件与响应区分、空值及零值、官方域名边界。真实账号测试需显式设置 `ANT_CHATGPT_TEST_PORT` 和 `ANT_CHATGPT_TEST_EMAIL`，正常测试不连接用户账号。
